# Weather-app
A modern and feature-rich Weather Application built with Flutter using Clean Architecture principles and BLoC state management. It provides users with accurate real-time weather data and forecasts for cities worldwide. 
✨ Key Features:
Liquid Glass UI Design: Sleek, modern interfaces with smooth dark and light mode adaptation.

Full Localization (Arabic & English): Seamless language switching with automatic RTL/LTR support and localized city/country names.

Smart Global Search: Search for any city or country worldwide with real-time suggestions powered by WeatherAPI.

Offline Caching: View previously fetched weather data locally using SharedPreferences.

Geolocation Support: Automatically fetches and displays weather information for the user's current location via GPS.

🛠️ Tech Stack & Architecture:
Framework: Flutter (Dart)

State Management: Flutter Bloc (flutter_bloc)

Dependency Injection: GetIt

Networking: Dio

Local Storage: SharedPreferences

Location Services: Geolocator & Geocoding
